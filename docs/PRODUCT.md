# Product

NO ZERO serves healthy adults 18–64 with a local-first indoor training system. The user journey is onboarding → safety screening → multidimensional assessment → four-week cycle → daily workout → post-session feedback → adaptation → dashboard/reassessment.

The product promise is not maximum exercise volume. It is a plan that respects capability, time, equipment, noise, recovery, and safety. A recovery day is a successful planned state. A minimum workout is a smaller version of the actual plan, not a random universal circuit.

V1 deliberately excludes social feeds, medical diagnosis, rehabilitation, child/elderly/pregnancy specialization, complete nutrition tracking, cloud video storage, and wearable dependencies.

V1 acceptance uses due-plan adherence, not session count, as the core execution metric. Planned recovery days are successful due days; a ZERO status is visible and ends the current streak without erasing long-term history.
